MALIVU 3D - NETLIFY
1. Upload this ZIP (or the extracted folder) to a NEW Netlify site using manual deploy / Netlify Drop.
2. Open the site's public URL to test the 3D viewer.
3. Copy your URL, for example https://your-site.netlify.app
4. In Shopify Custom Liquid, use the code in shopify-custom-liquid.txt and replace YOUR-NETLIFY-SITE with your actual Netlify site name.
NOTE: The model is an approximate prototype, not a precise reproduction of the jewelry.
